
# Searching and Sorting Algorithms

## 1. Linear Search
- Time Complexity: O(n)
- Space Complexity: O(1)
- Checks elements one by one until the target is found.
- Works with sorted and unsorted arrays.

## 2. Binary Search
- Time Complexity: O(log n)
- Space Complexity: O(1)
- Repeatedly divides the search range into half.
- Requires a sorted array.

## 3. Bubble Sort
- Best, Average and Worst Time: O(n^2)
- Space Complexity: O(1)
- Compares adjacent elements and swaps them when necessary.

## 4. Selection Sort
- Best, Average and Worst Time: O(n^2)
- Space Complexity: O(1)
- Finds the smallest remaining element and places it in the correct position.

## Automated Testing
Tests cover:
- Successful and unsuccessful searches
- Empty arrays
- Single-element arrays
- Negative and duplicate values
- Unsorted and already-sorted arrays
